## Built with

Plain HTML, CSS and vanilla JavaScript. No frameworks, no build step, no dependencies,
no trackers or cookies. Just open `index.html` in a browser.

Features: light/dark theme with saved preference, responsive layout down to mobile,
expandable project detail panels (native `<details>` — works without JS), CSS-only
architecture diagrams, and a print-friendly stylesheet.

## Editing

Everything lives in `index.html`. Styles are in the `<style>` block at the top —
the colour palette is defined once as CSS custom properties under `:root`
(and `html[data-theme="dark"]` for dark mode), so changing the accent colour is a
one-line edit. Content sections follow in order: hero, about, skills, experience,
projects, education, contact.

Commit a change to the default branch and GitHub Pages redeploys automatically,
usually within a minute.

## Note on project descriptions

Work completed for an employer is described at the level of business problem,
engineering approach and outcome only. Proprietary details — internal system names,
site and line identifiers, data schemas, and operational figures — are deliberately
excluded. No employer data, source code or screenshots are published in this repository.
