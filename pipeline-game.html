    Why this is the design decision that mattered

    Both approaches deliver identical data to the lake. The difference only shows up on the fourth source, and the fortieth — which is exactly when a platform either scales or starts to collapse under its own maintenance.

    • Hardcoded: effort is linear. Every source is a new build, every fix has to be repeated across every pipeline, and the object count grows without limit.
    • Metadata-driven: effort is front-loaded once. After that a new source is a configuration entry, logic lives in one place, and the pipeline estate stops multiplying — which is also what kept the platform inside its existing licence tier.

    In production this framework moves SAP and internal system data through CDS views into ADLS Gen2 for Power BI, handling up to a million rows per run — and it cut onboarding time for a new source by up to 60%.
